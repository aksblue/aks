# 📺 Anime Tracker Menu - iOS Shortcut

This is the **main shortcut menu** that helps you manage your anime tracking system. It gives you a simple menu with buttons for adding anime, checking your watchlist, editing dates, and more — all powered by other connected shortcuts.

### Features
- Menu-based launcher for different anime tracking actions.
- Add anime you're currently watching, already completed, or finished long ago.
- View your "Currently Watching" list.
- Search if you've watched something before.
- Edit anime details or the start date.
- Built-in exit button if you change your mind.

### Requirements
- **iOS Shortcuts app**
- Several connected shortcuts:
  - `Set Started Date Connected To Anime Watch List`
  - `Currently Watching List`
  - `Anime Watch List (csv) 1`
  - `Add pass anime`
  - `Did I Watched This?`
  - `Edit Anime List`
  - `Edit “Set Started Date”`

> If any of these are missing, some menu options won’t work.

### How to Use
Tap to open the menu and choose an action. Each button runs a different shortcut that’s part of your anime tracking system. Make sure you’ve installed all the connected shortcuts first.

### Dependencies
- Other Shortcuts: All the ones listed above must be installed.
- Jellycuts (optional): You can open or edit this menu layout using Jellycuts if you prefer working in code view.

### Note
This shortcut is **not a standalone tool** — it works as a controller for your anime tracking system.  
Make sure all connected shortcuts are installed and working before using this menu.
